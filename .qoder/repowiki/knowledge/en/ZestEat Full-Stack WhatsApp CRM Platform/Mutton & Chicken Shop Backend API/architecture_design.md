Single-process Node.js application rooted at `server.js`, which creates an Express app and a shared HTTP server that both Express and Socket.io attach to. Middleware stack: CORS (open), JSON/urlencoded bodies (50mb limit), static `/uploads` serving, then domain-scoped routes mounted under `/api/*` (`auth`, `users`, `leads`, `whatsapp`, `contacts`, `template`, `orders`, `menu`, `todos`, `paysip`, `analytics`). Data layer is Mongoose models under `models/` (User, Lead, Contact, Order, Template, Menu, Todo, PaySip, MessageLog, ProcessedMessage, MessageCache, MetaConfig) with schemas declaring field constraints inline. External integrations are isolated in `utils/`: `metaTemplateService.js` / `whatsappService.js` wrap Facebook Graph API via axios/form-data, `cloudinaryService.js` handles image upload, `conversationFlow.js` / `zestEatAutomationBot.js` implement bot logic. A global node-cron job runs every minute after MongoDB connects to invoke `runScheduledTemplates()` from `routes/template`. The module exports `{ app, server, io }` so the parent process can attach additional listeners or serve the frontend.
