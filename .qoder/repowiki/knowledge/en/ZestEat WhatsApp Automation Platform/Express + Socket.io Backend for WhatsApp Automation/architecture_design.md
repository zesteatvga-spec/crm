Single-process application rooted at `server.js` that creates an Express app and a shared `http.Server`, then attaches both Express routes and a Socket.io server to it. Middleware stack: CORS (open), JSON/urlencoded bodies with 50mb limits, static `/uploads` serving, then domain-scoped routers mounted under `/api/*` (`auth`, `users`, `leads`, `whatsapp`, `contacts`, `template`, `orders`, `menu`, `todos`, `paysip`, `analytics`). The data layer is Mongoose models under `models/` (User, Lead, Contact, Order, Template, Menu, Todo, PaySip, MessageLog, ProcessedMessage, MessageCache, MetaConfig) with inline schema constraints. External integrations are isolated in `utils/`: `metaTemplateService.js` / `whatsappService.js` wrap Facebook Graph API via axios/form-data, `cloudinaryService.js` handles image upload, `conversationFlow.js` / `zestEatAutomationBot.js` implement bot logic. A global node-cron job runs every minute after MongoDB connects to invoke `runScheduledTemplates()` from `routes/template`. The module exports `{ app, server, io }` so the parent process can attach additional listeners or serve the frontend.
