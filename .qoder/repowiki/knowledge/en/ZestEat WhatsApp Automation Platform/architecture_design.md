Two sibling applications share one repository with no shared code or build step: the `frontend/` SPA consumes REST endpoints exposed by the `backend/` server, while real-time broadcast between dashboard users is handled via Socket.io on the same backend. Cross-child coordination lives entirely in the HTTP/WebSocket contract (route paths, request/response shapes) rather than in any parent-level wiring; loose root assets (`Hackathon.jpeg`, WhatsApp template chart doc) are project collateral only.
